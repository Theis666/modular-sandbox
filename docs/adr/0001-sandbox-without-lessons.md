# Free sandbox instead of guided lessons

The learner is an absolute beginner, which usually suggests guided lessons. We deliberately chose a free sandbox and let Example Patches, Info Mode and per-module info pages carry the teaching, because the learner wants to explore and build playable patches rather than follow a course.

## Consequences

- Example Patches are the learning path and must each demonstrate exactly one concept.
- Explanations must be good enough to stand alone; there is no lesson text around them.
